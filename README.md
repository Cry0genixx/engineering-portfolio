# Engineering Portfolio

Technical engineering portfolio focused on mechanical engineering, manufacturing, mechatronics, industrial automation and systems integration.

## Portfolio Purpose

The purpose of this portfolio is to document verifiable engineering competence through structured technical projects.

Projects are developed using a requirements-driven engineering workflow:

Requirements:
-> Architecture;
-> Design;
-> Implementation;
-> Verification;
-> Documentation;

## Core Domains

- Mechanical Engineering
- Manufacturing & CNC
- Industrial Automation
- Robotics
- Electrical Engineering
- Industrial Networking / IT-OT
- Mechatronics
- Systems Engineering
